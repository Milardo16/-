# 🛒 Online Shop

## Описание проекта
Веб-приложение интернет-магазина с каталогом товаров и ролевой моделью доступа.

## Основные возможности
- Просмотр каталога товаров
- Авторизация пользователей (Spring Security)
- Роли: USER и ADMIN
- CRUD-операции над товарами (только для ADMIN)
- Валидация данных

## Стек технологий
- Java 17
- Spring Boot 3.3
- Spring Data JPA / Hibernate
- Spring Security
- Thymeleaf (HTML)
- PostgreSQL
- Flyway (миграции)
- JUnit 5 + Testcontainers
